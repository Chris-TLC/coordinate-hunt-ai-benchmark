# 盲区 / BLINDSPOT

## 设计约束

2026-09-05。一个梦里的、可以真正玩完的第一人称心理对战游戏。不是俯视射击游戏，也不是看得到敌人的 FPS。

- 两个镜像房间，均为 16 × 15 米。玩家与 AI 分处两个房间。
- 玩家只在自己的房间走动；朝真实存在于 3D 房间的巨幕开枪，将落点映射到对面房间。
- 巨幕永远不绘制敌人模型、头像或实时位置点，只显示短暂模糊声纹和侦测轨迹。
- 每局 120 秒；击败对方立即结束，时间耗尽比较生命值，相同则平局。
- 原生 WebGL、Canvas、Web Audio；无第三方运行时、远程素材、字体或网络请求。支持 file://。

## 视觉与手感

选用安静的旧式实验教室，而非霓虹赛博、军事写实或全屏雷达。墨绿混凝土、米白标识、薄荷绿荧幕、少量赭红警告。建筑有梁柱、吸音板、灯槽、门窗、落地线缆、编号掩体；低对比度颗粒与柔和光照保持克制。标题界面直接透过玻璃式排版看到实时房间。

武器是一把代码建模的白色脉冲手枪，六发弹匣，有扳机、后坐力、机械换弹动画和合成音效。鼠标转头，WASD 移动，左键开火，右键精瞄，R 换弹；Shift 疾跑，C 静步。E 投放局部侦测脉冲，Q 留下延迟伪声。受击短暂加速，避免连续压制成为无解循环。

## 对局闭环

开场三个短句解释：看残影 → 朝地图开枪 → 开枪后换位。首局提供上下文引导而非强制教程。音频在开始按钮交互后启用。Esc、失焦、切换标签均暂停，并释放鼠标；恢复必须由用户交互触发。

AI 只依据交付给它的声纹记忆、探测结果和落弹预警决策，不读取玩家位置来瞄准。攻击有飞行延迟，可根据痕迹方向预判；障碍限制移动并阻挡邻近爆炸伤害。提供三档 AI 难度、鼠标灵敏度、音量、画质、减少晃动选项。结算显示胜负、命中率、伤害和再次入梦入口，战绩仅保存在浏览器本地。

## 实现与验证顺序

1. 独立纯 JS 对局模型：测试地图映射、移动碰撞、弹药、扫描信息隔离、AI 感知、伤害与 120 秒结算。
2. 原生 WebGL 几何批次、程序纹理、动态地图、房间与武器。
3. 主菜单、HUD、输入、音效、暂停、设置、复盘与本地统计。
4. Node 测试、浏览器真实交互、截图检查、离线单文件构建与文件打开验证。

## 文件职责

- `src/simulation.js`：可重复随机数、规则与 AI，兼容 Node 测试。
- `src/renderer.js`：矩阵、网格、光照、世界、武器与特效。
- `src/tactical.js`：只根据可见信息生成巨幕 Canvas 纹理。
- `src/audio.js`：合成空间音效和环境音。
- `src/game.js`：浏览器生命周期、输入、DOM、持久化。
- `index.html` / `styles.css`：完整界面。
- `tools/build.mjs`：合并为一个可双击、可转发的离线 HTML。

## 验收

首屏一键开始；30 秒内能理解目标；完整 120 秒或击杀结算；非作弊的 AI；真实 3D 空间和屏幕点到房间点的映射；无网络资源；首次音频启动、暂停、重开、设置和低画质可用。截图和临时浏览器测试产物放在仓库外。
