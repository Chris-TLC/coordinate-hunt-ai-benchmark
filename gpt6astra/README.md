# 盲区 / BLINDSPOT

**看不见，不代表不在。**

一款从梦里生长出来的第一人称心理对战游戏。你站在自己的房间，看着对面房间的俯视图。你永远看不到对手，只能看到他的枪声残影与脚步轨迹。朝地图开枪，子弹落到对面的对应位置；开枪也会暴露你的旧位置。

## 直接玩

**双击 `盲区.html`，用 Safari 或 Chrome 打开，点击「进入梦境」。**

不需要安装，不需要账号，不需要服务器，不需要联网。`盲区.html` 是完整单文件，可以直接复制、AirDrop 或发送给朋友。也可以打开同目录的 `index.html`，但该方式需要同时保留 `styles.css` 和 `src` 文件夹。

需要支持 WebGL 的桌面浏览器、键盘和鼠标／触控板。浏览器无法锁定鼠标时会自动改为触控板模式。首次启动声音由「进入梦境」按钮解锁。

## 三句话

1. **读残影**：巨幕是对方房间的地图，不是监控。残影是过去，不是实时人影。
2. **猜落点**：瞄准地图左键开枪，约 0.52 秒后子弹抵达。直击 34，擦伤 18，三次直击可获胜。
3. **立刻换位**：你开枪的位置也会成为对方的线索。留在原地，下一发可能就轮到你。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | W A S D |
| 转向 | 鼠标；也支持方向键 |
| 开枪 | 鼠标左键，按住可连续开火 |
| 精瞄 | 鼠标右键或 F |
| 换弹 | R，六发弹匣，1.55 秒装填；空弹时再次开火自动换弹 |
| 疾跑 | 按住 Shift，声纹更明显 |
| 静步 | 按住 C，移动更慢但不广播普通脚步 |
| 局部侦测 | 瞄准地图后按 E，半径 2.8 米，持续 3.6 秒，14 秒冷却 |
| 延迟伪声 | Q，原地留下假脚步，1.3 秒后启动，20 秒冷却 |
| 暂停 | Esc；切换标签或失焦也会自动暂停 |
| 静音 | M |

触控板模式下，鼠标自由瞄准，**右键拖动转向，F 精瞄**。在设置中可主动切换控制模式。

## 一局的规则

- 两间镜像房间均为 **16 × 15 米**。单人对电脑，1v1。
- 每回合 **120 秒**，暂停期间不计时。
- 生命归零立即结束；超时比较生命值，相等则平局。
- 两方使用相同的伤害、弹药、碰撞和技能规则。
- 弹丸会被落点上的障碍物挡住；掩体也能阻隔近距离溅射。
- 受到伤害后有 1.65 秒的逃生加速。
- AI 依据它收到的声纹、探测轨迹与落弹预警行动；不读取你的实时位置来瞄准。
- 结算后可以立即重开。设置和对局记录仅保存在当前浏览器的本地存储中；浏览器限制文件存储时，不影响游戏本身。

## 设置

右上角可调整三档 AI 难度、灵敏度、音量、视角模式和画质。MacBook 发热时可切到「节能」；容易晕 3D 时打开「减少镜头晃动」。难度在下一局生效。佩戴耳机更容易辨认左右声纹。

## 素材与技术

零外部素材，零第三方运行时依赖，零网络请求。房间、枪械、障碍、光照和特效由原生 WebGL 几何与着色器生成；巨幕、图例和导航图由 Canvas 2D 绘制；所有枪声、脚步、回声与环境音由 Web Audio 合成；界面只使用系统字体。

## 开发与验证

以下命令仅用于修改源码，不是玩家运行游戏的前提。

```sh
npm test
npm run build
npm start
```

`npm test` 使用 Node 内置测试运行器，不需要安装依赖。`npm run build` 将源码合并为 `盲区.html`。`npm start` 是可选的本地预览服务器，监听 `127.0.0.1:4173`。

架构与设计约束见 `docs/DESIGN.md`。
