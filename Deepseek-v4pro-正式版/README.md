# 对影 MIRRORROOM · 隔墙对局

> 你在一个封闭房间里,面前是一整面墙的巨幕。巨幕里是**对面房间**的俯视平面图——你看不见对手,只能看见他留下的光影痕迹、听见他的脚步声。朝屏幕上的位置开火,子弹会落在对面房间的同一位置。猜中,他受伤;猜错,你暴露。一局 120 秒,三枪定胜负。

## 怎么玩

1. **双击 `mirrorroom.html`**,用 Chrome / Safari / Edge 打开(不需要联网,不需要装任何东西)。
2. 选难度,点 **开始对局**(鼠标会被锁定)。
3. 玩。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` | 移动 |
| `Shift` | 奔跑(更快,但脚步更响、地图上会留下轨迹) |
| 鼠标 | 环视 / 瞄准 |
| 左键 | 朝巨幕上的瞄准点开火(0.85s 冷却) |
| 右键 | 发射侦测器(冷却 9s):范围内有人会被锁定,无人显示"无信号";**敌方也能看到你的脉冲** |
| `Esc` | 暂停(可调灵敏度 / 音量) |
| `M` | 静音切换 |

## 你能获得的信息(和对手一样)

- **轨迹**:对方奔跑时,地图上会留下短暂的光影拖痕;走路几乎不暴露,但慢。
- **脚步声**:透过墙传来,越靠近巨幕越响、越靠左/右越偏;躲在障碍物后方(声影区)脚步声更轻。
- **射击光束**:对手开枪时,你这边能看到一道光从巨幕边缘打进你的房间——"屏幕边缘亮了一下"。命中你时视野变红。
- **涟漪**:在原地站太久,地图上会泛起微弱涟漪。
- **终局扫描**:最后 25 秒,系统每 6 秒全域扫描一次,双方位置短暂暴露——逼迫决战。

被击中后你会短暂加速(肾上腺素),可以靠走位甩掉"追猎"。

## 胜负

- 击杀对手(3 枪)→ 胜;
- 120 秒结束 → 生命值高者胜,相同则平局。

## 文件说明

- `mirrorroom.html` —— **成品**,单文件、完全自包含、完全离线。
- `dev/` —— 源码与工具:
  - `dev/parts/*.js` —— 按模块拆分的源码(常量/AI/渲染/音频/对战/HUD/主程序);
  - `dev/build.sh` —— 把 parts 合并进单文件 HTML;
  - `dev/sim-test.mjs` —— 无头 AI 对战模拟(平衡性测试);
  - `dev/px-qa.py` —— 截图像素 QA(PIL);
  - `shots/` —— 开发期截图。

想调数值(伤害、冷却、AI 强弱等):改 `dev/parts/00-const.js` 后运行 `dev/build.sh`。

## 技术说明

- 渲染:自写 Canvas 2D 射线投射(raycasting)引擎,第一人称 3D + 巨幕蓝图位图逐列采样,零外部素材;
- 音频:WebAudio 全程序合成(脚步、枪声、侦测脉冲、心跳、氛围嗡鸣),零音频文件;
- AI:信念热力图(把声音/轨迹/涟漪/扫描转换成"对手位置"的概率场)+ 狩猎/埋伏/闪避三情绪状态机;
- 无框架、无网络请求、无字体/图片/音效资源,~98KB 单文件。
