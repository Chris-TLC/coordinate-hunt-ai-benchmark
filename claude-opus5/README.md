# 坐标猎场 · COORDINATE HUNT

> 隔着一面墙的对决。
> 你看不见他,他也看不见你 —— 你们只能看见对方留下的痕迹。

一款从梦里捞出来的第一人称心理博弈游戏。零依赖、零素材、零联网,
所有画面与音效都由代码在运行时生成。

---

## 怎么玩

**双击 `启动坐标猎场.command`** —— 就这一步。

或者直接用浏览器打开 `index.html`(全部素材都是代码生成的,不需要服务器)。

> 建议 Chrome / Edge / Safari 最新版。进入对局后浏览器会请求锁定鼠标,
> 这是第一人称视角需要的;按 `Esc` 可随时释放并暂停。

---

## 玩之前只需要知道三件事

1. **你面前那块巨幕,是对手房间的俯视图。**
   两间房完全一样(16m × 15m),但屏幕上永远看不到人。
2. **朝你猜他在的位置开枪 —— 打的是地图上的坐标。**
   子弹落在对面房间的对应位置。猜对了他就受伤。
3. **但你开火的位置,也会亮在他的屏幕上。**
   每一枪都是一次交易:你换来一次机会,也交出自己的坐标。

## 巨幕上会出现什么

屏幕上没有小人,只有痕迹。学会读它们,就是学会这个游戏。

| 痕迹 | 含义 |
| --- | --- |
| 🟠 **橙黄光团 + 十字** | 他刚刚在这里开了一枪 —— 最可靠的情报 |
| 🟡 **淡淡的拖痕** | 他走过这里,箭头指向来向 |
| 🔴 **暗红热斑**(会呼吸) | 他在这里站太久了,体温烧出来了。越亮越准 |
| 🔵 **青色扩散环** | 你自己的弹着点,虚线圈就是命中判定范围 |
| 🟢 **绿色方框** | 侦测器扫描中,结束时显示「有人」或「空」 |
| 🔴 **红色轨迹线** | 侦测器抓到人了 —— 这是他最近几秒的完整走位 |

左右两翼是实时数据:左边是战况日志,右边是双方血量、弹药、
以及一条 **暴露风险** —— 它告诉你「他现在有多确定你在哪」。
开枪之后看着它冲高,你就明白为什么要换位置了。

## 三条路,每条都要付代价

这是整个设计的核心。房间是封闭的,没有藏身之处:

```
        动  →  在他屏幕上留下移动残痕
      不动  →  体温慢慢烧出热痕,越站越亮越准
      开枪  →  直接把自己的坐标点亮给他
```

没有稳妥的选择,只有权衡。所以你会开始算:
他上一枪打在哪,说明他以为我在哪;我要不要故意在那边走两步;
这一枪我有几成把握,值不值得为它暴露一次。

## 对手

AI 和你吃**完全相同**的信息。它看不见你,只能通过

- 你开火时在它屏幕上炸开的闪光
- 你移动留下的残痕
- 你站着不动烧出的热痕
- 它自己投放的侦测器

来推断你的位置。内部维护一张 32×30 的概率信念网格,随时间扩散、
随证据收敛;开火前它会在信念上搜索**命中概率最高的落点**,
只有概率够高才扣扳机 —— 因为它也知道,开枪就是暴露。

| 难度 | 特点 |
| --- | --- |
| **侦察兵** | 反应慢、手抖、爱等把握 |
| **猎手** | 会预判你的走向,打完就换位置 |
| **幽灵** | 推断锐利、反应极快、几乎不浪费子弹 |

数值经过 **每组 200 局的无头模拟**批量调校:

| 对手 | 新手 | 会走位 | 高手 | 一局时长 |
| --- | --- | --- | --- | --- |
| 侦察兵 | 51% | 64% | 81% | 42–60s |
| 猎手 | 20% | 38% | 53% | 36–39s |
| 幽灵 | 10% | 24% | 33% | ~30s |

蹲着不动的胜率在所有难度下都是 **0%** —— 这是刻意的。

## 规则速查

- 一回合 **120 秒**;时间到时血多者胜
- 生命 100;直击 **-22**,擦伤 **-11**(需要 5 发直击才能击倒)
- 命中判定:核心半径 **0.80m**,擦伤半径 **1.45m**
- 弹夹 5 发,两枪间隔 2.0s,打空换弹 2.6s
- 侦测器冷却 11s,扫描范围 5.2m × 5.2m
- 受击后获得 3.2 秒 **肾上腺素**:移动加速,方便脱离

## 技术

纯手写,单页面,无构建步骤,无第三方库。

| 文件 | 职责 |
| --- | --- |
| `js/00_util.js` | 数学工具 |
| `js/01_audio.js` | WebAudio 程序化合成音效(无音频文件) |
| `js/02_tex.js` | Canvas 程序化贴图(无图片文件) |
| `js/03_gl.js` | WebGL 微引擎:多贴图批次、半球光照 + 灯阵光池、雾 |
| `js/04_world.js` | 房间尺寸、布局生成、碰撞 |
| `js/05_plan.js` | **巨幕** —— 2560×1024 动态贴图,游戏的灵魂 |
| `js/06_fx3d.js` | 场景几何、粒子、弹道、立体光效 |
| `js/07_ai.js` | 贝叶斯信念网格 + 命中概率决策 |
| `js/08_game.js` | 规则、回合流程、玩家控制、HUD |

一帧的开销(2880×1800 Retina 缓冲、满负载 135 条痕迹 + 420 粒子):

```
巨幕重绘  0.46 ms
贴图上传  0.03 ms
AI  决策  0.06 ms
────────────────
合计     ~0.55 ms   (单帧预算 16.7 ms)
```

### 开发工具

```bash
node tools/balance-sim.js 200        # 跑平衡模拟(全难度 × 5 种玩家策略)
node tools/balance-sim.js 200 hard   # 只跑指定难度
```

模拟器直接加载游戏的真实逻辑模块(`04_world.js` / `07_ai.js`),
所以它测的是真的 AI,不是另写一套近似。支持用环境变量覆盖任意规则参数扫参:

```bash
R_DMG_CORE=18 R_RELOAD=2.4 node tools/balance-sim.js 200 std
```

## 场地约定(设计约束)

- 场地 **16m 宽 × 15m 深**,挑高 6.4m
- 巨幕占满 -Z 整面墙;**靠幕一侧不放任何高于视线的物体** ——
  玩家在房间任何位置都必须能看见完整的巨幕
- 高掩体压在房间后半部,前半部只放及腰障碍
- 后墙是一道锁死的气密门:这个房间没有出口
