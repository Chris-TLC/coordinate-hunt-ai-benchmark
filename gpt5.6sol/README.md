# 视差协议

一款离线浏览器第一人称 1v1 坐标猎杀游戏。你看不见对手，只能从巨幕上的脚步、疾跑、开火和扫描痕迹推断位置，再向地图坐标开火。

## 开始游戏

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，点击“进入房间”即可。仓库已经包含可直接游玩的单文件成品：双击 `dist/index.html`，不需要安装依赖或启动服务器。重新生成生产版可运行 `npm run build`。

所有画面、纹理与音效均由本地代码生成，不依赖联网素材。

## 操作

- `WASD`：移动
- `Shift`：疾跑（更快，但会留下更清晰的线索）
- `鼠标`：观察和瞄准巨幕
- `左键`：向巨幕地图对应坐标开火
- `Q`：向当前地图坐标投放侦测器
- `Esc`：暂停并释放鼠标

每局 120 秒，命中造成 34 伤害。优先击倒对手，或在时间结束时保有更多生命。
