# 坐标猎场

《坐标猎场》是一个可在 MacBook 本地运行的第一人称 3D AI 1v1 测试版。双方不能直接看见彼此，只能通过巨幕坐标图、延迟暴露区域和单次轨迹侦测判断对方位置。

## 当前状态

- 可用能力：本地 3D 1v1 对局、AI 对手、巨幕坐标攻击、单次轨迹侦测、回合与整场结算。
- 当前限制：WebGL、Pointer Lock 和键鼠完整流程仍需真实浏览器手工验证；生产构建存在单 chunk 大于 500 kB 的非阻断警告。
- 下一步：取得用户对下一项玩法改动的明确目标与验收标准。
- 最后验证：2026-08-11，`scripts/check.sh` 通过（31 项测试，lint 与构建成功）。

## 一键启动

双击 `启动坐标猎场.command`。脚本会在需要时安装依赖、启动本地服务，并在默认浏览器打开游戏。

也可以在终端运行：

```bash
cd "/Users/mac/Developer/游戏demo"
pnpm install
pnpm dev --host 127.0.0.1 --port 4173
```

随后打开 <http://127.0.0.1:4173/>。

要求：macOS、Node.js 20.19 或更高版本，以及 pnpm。首次启动需要本机已有这些开发工具；游戏运行本身不调用外部服务或 AI API。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 观察与瞄准 | 移动鼠标或触控板 |
| 向巨幕坐标开火 | 鼠标左键 |
| 使用本回合唯一一次侦测 | 鼠标右键或 `E` |
| 暂停并释放鼠标 | `Esc` |

点击“开始对弈”后，浏览器会锁定鼠标。若浏览器拒绝 Pointer Lock，游戏会自动切换到窗口内鼠标控制。触控板可用双指点击进行右键侦测，也可直接按 `E`。

## 规则摘要

- 场地尺寸为 16 × 15 m，巨幕前 2.5 m 禁止进入，三块障碍会阻挡移动。
- 双方各 3 HP，每发攻击以巨幕坐标为圆心、1.5 m 为命中半径。
- 武器冷却 1.5 秒；开火位置在约 0.4 秒后以 3 × 3 m 区域暴露 1.2 秒。
- 每回合可侦测一次，半径 4 m；命中时显示敌方此前 1.5 秒的冻结轨迹。
- 受击后立即红屏，并在 1.5 秒内从 5 m/s 加速到 6.5 m/s。
- 单回合 120 秒，先赢 3 回合者赢得整场；同一结算 tick 双方同时致死判平局。

AI 不读取玩家实时位置来瞄准。它只能使用公开暴露区、自己的侦测结果、延迟命中反馈和受击事件；难度只改变反应时间、瞄准误差和决策频率，不修改双方的 HP、速度、冷却、命中半径或信息权限。
