# AGENTS.md

## 项目定位

- 项目名称：坐标猎场（游戏demo）
- 项目目标：维护一个可在 MacBook 本地运行的第一人称 3D AI 1v1 游戏 Demo。
- 档位：轻档

## 技术栈

- 语言与版本：TypeScript 5.9.3；Node.js 20.19 或更高版本
- 包管理器：pnpm 11.x
- 应用框架：React 19、Three.js 0.185、Vite 8
- 测试框架：Vitest 4；另用 ESLint 9 与 TypeScript 构建检查

## 目录边界

- 主要源码：`src/`，其中游戏逻辑在 `src/game/`，界面组件在 `src/ui/`
- 测试：与实现同目录的 `src/**/*.test.ts`
- 生成物：`dist/`、`node_modules/`，均不提交
- 数据：无独立运行时数据目录；概念文档位于项目根目录

## 权威文件

- 项目规则：`AGENTS.md` 与 `CLAUDE.md`
- 当前状态和下一步：`README.md`
- 变更历史：Git log 与远端提交
- `PROJECT_MEMORY.md`：旧 Hermes 范式快照，仅供追溯，不在启动时读取，不再更新

## 开工顺序

1. 读本文件。
2. 读 `CLAUDE.md` 中与角色无关的共享规则。
3. 读 `README.md` 的当前状态和下一步。
4. 运行 `git status --short --branch`。
5. 确认本轮用户请求和禁改范围。

## 实施边界

- 只修改与当前任务直接相关的文件。
- 保留用户已有改动。
- 不自动 add 未跟踪文件。
- 不做无关重构。
- 新增依赖前说明必要性。
- 修改规则、AI 信息权限或命中判定时，必须补充或更新对应测试。

## 禁区

- 不读取或提交密钥。
- 不修改 `dist/` 等生成物，除非任务明确要求重新生成。
- 不删除概念文档、历史文件或用户数据。
- 不让 AI 读取玩家实时位置进行瞄准。
- 不改写 Git 历史。
- 不执行未经授权的 push。

## 唯一验证入口

```bash
scripts/check.sh
```

不得绕过失败步骤。

不得用较窄的单项测试替代最终完整验证。

真实浏览器交互不属于自动化入口；涉及 WebGL、Pointer Lock 或键鼠流程的改动，完成前另做对应手工验证。

## 完成标准

- 任务验收项全部满足。
- `scripts/check.sh` 退出 0。
- diff 中没有无关改动。
- 工作区状态已如实报告。
- 未声称无法由证据支持的结果。

## AGENT_LOG.md 按需读取规则

AGENT_LOG.md 启动时不读。仅在以下情况读：
（1）你的方案与既有实现冲突，需要知道此前为何这样做
（2）你打算采用的方案疑似此前已被否决
（3）用户明确要求追溯

它记录试过但未落地的尝试、为什么放弃、踩过的坑。
不记录当前状态（那是 PROJECT_MEMORY.md 的职责）。
不记录规则（那是本文件的职责）。

本项目采用轻档，当前状态实际由 `README.md` 承接；现存 `PROJECT_MEMORY.md` 仅保留为旧范式历史快照。
